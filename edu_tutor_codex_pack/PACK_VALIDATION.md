# 이 명령어 묶음 자체의 검증 기록

작성일: 2026-10-25

이 기록은 **개발 지시서와 예제 파일의 형식 검사**다.
앱 구현, 실제 LLM 실행, GPU 학습, 음성 생성, 사진 인식, 화면 렌더링을 수행했다는 의미가 아니다.
그 작업은 이 팩을 전달받는 개발 에이전트가 수행해야 한다.

| 검사 | 결과 | 확인 범위 |
|---|---|---|
| JSON 파일 구문 검사 | 통과 | 스키마·예제·상태 템플릿을 UTF-8로 파싱함. |
| YAML 설정 템플릿 검사 | 통과 | 설정 파싱 및 단일 GPU·자동 승격 금지 확인. |
| JSON Schema와 예제 일치 | 통과 | 교육 예제와 판서 계획의 필수 필드·타입·허용 명령 검사. |
| 스키마 거절 검사 | 통과 | 허용하지 않은 판서 명령과 빈 발화가 거절됨. |
| 예제 판서 참조 검사 | 통과 | 단계 ID·표 너비·강조 행·캐릭터 지시 대상이 일치함. 실제 렌더링 검증은 아님. |
| 설명용 SQL 기대값 검사 | 통과 | SQLite 임시 DB에서 개발 [3,2,1500,750], 운영 [3,2,1200,600] 확인. LLM 추론 결과가 아님. |
| 전달 경로·문자 인코딩 검사 | 통과 | 시작 문구·핵심 지시서 파일 존재와 UTF-8 무결성 확인. |

## 수행하지 않은 작업

실제 사용자 PC 접근, GPU 동작 확인, 모델 다운로드, 모델 학습, 웹 앱 구현·실행, 음성 청취, 사진 인식 정확도 평가.
