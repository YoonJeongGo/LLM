## 보존 범위

N01의 중간 질문 전·보충 설명 중·원수업 복귀 화면 3장을 담았습니다. 다른 수업의 단계별 표·수치·대사는 JSON에서 볼 수 있습니다. 독립 실패, 개발 회귀와 저장 수업 재생은 각각의 측정 조건을 따릅니다. 공개용 실행 기록은 원래 프로젝트의 결과에서 지정한 필드를 추출했습니다. 역사적 보고서의 세부 파일명은 측정 당시 원본의 위치를 가리킵니다. 개인 환경 파일, 학생 자료, 인증·승인 장부, 원시 HTTP 기록과 설치된 모델은 개별 PC에서 관리됩니다. 파일별 SHA-256과 원본 위치는 [manifest.json](manifest.json)에 있습니다.
