# final07 N01 부분집합 — 실제 내용·복귀 확인

사전 등록한 `final07-n01-regression.json`의 기존 N01 한 수업, 초기 질문과 보충 질문 두 개만 판정했다. 공개된 문항의 **개발 회귀**이며 final06 N02·반복 및 새 독립 N03와 분모를 섞지 않았다. 학생 질문·원본 표·동결 설명 기준은 그대로다.

| 기준 | 결과 |
|---|---:|
| 원시 모델 SQL 의도·결과 | 2/2 |
| 앱 검증 SQL | 2/2 |
| 실제 연결된 설명 | 2/2 |
| 대사·판서 내용 요구 | 8/8 |
| 보충 자연 종료 후 복귀 | 1/1 |
| 이 부분집합의 요구사항 검증 | 9/9 |
| 고유 단계의 실제 재생 연결 | 12/12: 초기3+보충9 |

초기 대사는 원본8행의 조건 계산→정렬→5행 결과를 전달했다. 보충은 선택 P3의 포함, P2의 제외, 명시한 P1 NULL과 P6 숫자0의 차이를 원본 조건으로 설명했다. s6~s9에서 **zone ASC → delta DESC → parcel DESC, 앞 키가 같으면 다음 키를 비교하는 규칙**을 유지한다. P5의-4가 같은 zone의 P1 NULL보다 앞서는 이유, zone 전환, P6의0과 P3의-4 비교, 현재 완전동점 없음과 모든 키 동점의 내부 순서 미보장을 실제 읽고 같은 비교 표에 표시했다.

이번 실제 대사·판서는 final06 N01과 정확히 같았지만 이전 재생을 이번 증거로 대신하지 않았다. 새로운 request→assistant message→lesson ID와 collector의 native playing 연결을 대조했다. 원수업의 내용 있는 표·선택 셀·단계·음성 위치로 복귀했고 보충9단계는 모두 자연 종료했다. 원수업의 전체 종료와 완료 화면 재진입도 별도 실행 기록에 있다.

원시 모델의 보충 **설명 오류는 남아 있다.** SQL은 맞지만 P1/P6을 제외한다고 말한다. 앱은 같은 SQL을 유지하면서 검증된 OR 계산으로 둘 다 포함된다는 대사를 읽었다. 따라서 원시 SQL2/2가 원시 설명 전체 정답을 뜻하지 않는다.

이번 텍스트 답변은 실제 새 생성이지만 WAV는 모두 기존의 정확히 일치하는 캐시를 재사용했다. 새 음성0이며 새 합성 지연을 측정한 실행이 아니다. 내용9/9는 제품 완성률·일반 교육 정확도가 아니다. 첫 설명34.7406초/보충17.8638초, 복귀 공백2.0881초는 별도 지연 판정이며 엄격2초 기준을 넘긴 공백을 복귀 성공으로 통과시키지 않는다. 사람 교육·발음·청취는 **H_PENDING**, 전체는 **NOT_READY**다.

평가 도구는 기존 원시 SQL·SQLite 대조 함수를 재사용했고, 사전 등록한 부분집합 해시와 원래 N01 문항 동일성을 확인했다. 내용 판정은 실제 대사·판서를 읽은 AI 검토이며 PASS 상태의 정확한 집합으로만 집계했다. 기존 final06의4질문18/18, 최초 독립 실패, N03는 수정하지 않았다. 이 판정 중 제품 수정·API·운영 DB·WAV 직접 접근·모델 실행은0이다.
