# 이전 소스 배포본과 학습 1 기록

2026년 10월 25일부터 29일까지 만든 소스 ZIP 세 개를 보존했다. [원본·게시본 크기와 SHA-256](archive-manifest.json)에서 각각의 출처와 달라진 파일을 확인할 수 있다.

- 0.1.0 ZIP은 기존 배포본과 바이트 단위로 같다.
- 0.2.0 두 게시용 사본은 `scripts/phase2_finalize.py`가 바탕화면의 원본 명세 파일 두 개를 찾을 때 `Path.home() / "Desktop"`을 쓰도록 수정했다. 기존 개인 홈 경로가 있던 두 줄과 내부 `RELEASE_FILES.json`의 해당 체크섬이 달라졌다. 파일명·파일 수·나머지 멤버 내용은 기존 ZIP과 같다.
- 세 ZIP 모두 CRC와 개별 멤버 체크섬을 확인했다. 테스트 이미지 세 개와 프로젝트 자작 예제는 포함되어 있다.

[학습 1 기록](training1-record.json)에는 합성 자료 출처, 학습 설정, 재로딩 검증, 미채택 사유와 로컬 어댑터·체크포인트의 크기·체크섬이 있다. 해당 학습은 240건, 3 epoch, 90 optimizer step으로 끝났다. 학생 앱은 기본 모델을 사용한다.
