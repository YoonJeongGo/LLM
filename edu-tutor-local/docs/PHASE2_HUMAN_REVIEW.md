## 4. T04 — WHERE → GROUP BY → 집계 → HAVING

실제 입력 6행 중 WHERE를 통과한 5행을 3그룹으로 묶었습니다. 집계는 A=`2,10,10`, B=`1,40,40`, C=`2,80,40`이며 HAVING 뒤에는 A와 C만 남습니다. 표시하는 값의 순서는 `people,total,average`입니다. 이는 **학습용 논리 단계**이며 실제 엔진의 물리 실행 추적이 아닙니다.

강의 ID: `54b6ed615be74703bf8ef97b907978cd`.
[실제 입력·계산·4단계 기록](../runs/phase2/current/live/T04-group.json) · [화면/값 대조 기록](../web/test-results-phase2-content/T04-evidence.json) · [그룹 화면](../web/test-results-phase2-content/T04-390-step2.png) · [최종 결과 화면](../web/test-results-phase2-content/T04-390-step4.png) · [1단계 음성 10.40초](../.local/audio/f01b972e90d3006321598619d7e3c933de50957a8967f38f541e6efb180dd394.wav).

**실제 음성은 1단계만 있습니다.** 2~4단계는 판서·자막·수동 이동 확인 범위이며 음성을 들었다고 체크하지 않습니다. 글자 200%에서 넓은 표는 표 안에서 좌우로 스크롤합니다.

- [ ] **정확함:** 필터·그룹·집계·HAVING 결과가 입력 행과 맞고 논리 단계와 물리 실행을 혼동하지 않는다.
- [ ] **이해됨:** 같은 원본 행을 유지하며 중간 표와 최종 A/C 결과를 따라갈 수 있다.
- [ ] **말·판서 일치:** **1단계 음성**은 6행 중 5행 통과와 맞고, **2~4단계 자막**은 해당 판서와 맞는다.
