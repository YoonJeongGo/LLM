# 운영

처음 앱을 실행하면 로컬 토큰 파일을 생성한다. 브라우저의 연결 화면에서 입력한다. 외부 네트워크 바인딩, 공개 배포, 유료 API는 기본 구성에 없다. 원문·모델·음성은 로컬에 저장된다.

작업이 진행 중이면 관리자에서 상태와 취소를 확인한다. GPU는 동시에 하나의 작업만 소유한다. 텍스트 모델을 내리고 다음 음성/사진 worker를 실행하므로 첫 결과와 모델 교체 시간이 걸린다. 응답 시간이 보장되는 서비스가 아니다.

서버를 재시작하면 미완료 작업은 interrupted가 된다. 기존 대화와 업로드는 보존된다. 외부 프로세스를 PID 번호만 보고 종료하지 않는다. 모델이 없거나 패키지가 누락되면 실제 오류 상태를 표시하고 예제 답변으로 대체하지 않는다.

DB 백업은 CLI `backup`을 사용한다. 백업에는 민감한 대화가 들어갈 수 있으므로 로컬에서 보관한다. 원본 ZIP과 소스 release는 개인 데이터 백업을 대신하지 않는다. 디스크 정리나 모델 삭제는 사용자가 대상을 확인하고 별도로 지시해야 한다.
