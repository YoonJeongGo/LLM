AI 강사 통합 실행 지시 v2 — 전달 방법

이 패키지는 완성된 앱이 아니라 Codex 개발 지시서다.
사용자 PC의 코드·프로세스를 여기서 열거나 실행·학습·합성한 결과가 아니다.

방법 A: EDU_TUTOR_FINISH_MASTER_V2_KO.txt를 Codex에 첨부하고
START_HERE_KO.txt의 내용을 채팅에 붙여 넣는다.

방법 B: ZIP을 풀어 edu_tutor_finish_v2 폴더를 작업 공간에 두고
START_HERE_KO.txt를 보내 MASTER_KO.txt를 읽도록 한다.
두 방법 중 하나만 사용한다. 옛 명령어들을 모두 다시 보낼 필요는 없다.

같은 작업 폴더인지 확인한다: D:\LLM\edu-tutor-local
실행 도구나 실제 권한이 막히면 그 범위를 확인해야 한다.
문구만으로 권한·세션 제한을 없앨 수는 없다.

이번의 가장 중요한 변경:
- 받은 보고서는 2026-10-27 기록이므로, 10월28일 통합 지시 수신·실행 여부부터 확인.
- 별도 새 예산이 아니라 동일 승인 ID를 이어 사용. 기존 사용량 초기화나 중복 지급 금지.
- 실패한 Qwen TTS 세션 분석을 제품 전체의 선행조건으로 두지 않음.
- 실제 교육 학습·모델 평가·로컬 음성 대안·새 수업 검증을 한 작업으로 연결.
- 새 엔진·권한·속도·정확도는 실제 확인. 사람 검토를 대신 작성하지 않음.

전달 시 허용되는 상한:
로컬 모델 작업 최대8시간, 추가 학습 최대2실험, text800회, TTS120회,
사진30회, 공식 다운로드12GB. 이전 동일 승인에서 사용한 양은 차감한다.
프로젝트 총50GB/C여유50GB, 유료 호출·개인 자료 외부 전송 금지는 유지한다.
8시간은 완료까지의 예상 시간이 아니다. 모두 소진하라는 뜻도 아니다.

명령어 하나가 목표 성능이나 전부 완료를 보장하지는 않는다.
실제로 된 것과 남은 문제를 구분하고, 사람이 검토할 수 있는 버전까지
연결하는 실행 기준으로 사용한다.

POLICY_REFERENCE.json은 설정 참고 자료다.
기존 프로젝트 정책 파일을 이 파일로 덮어쓰거나 그대로 실행하지 않는다.
기존 정책 스키마에 맞게 최소 변경으로 적용하고 실제 유효 한도를 검사해야 한다.
