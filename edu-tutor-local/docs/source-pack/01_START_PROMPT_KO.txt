첨부하거나 작업 공간에 둔 edu_tutor_codex_pack을 이번 프로젝트의 통합 개발 요구사항으로 사용해라.
이전 대화를 알지 못하더라도 이 묶음만으로 작업할 수 있도록 작성되어 있다.

먼저 기존 프로젝트와 AGENTS.md를 확인하고 사용자 변경 사항을 보존해라.
그다음 02_MASTER_INSTRUCTIONS.md와 specs/00_EXECUTION_PLAN.md를 읽고,
각 단계에 필요한 상세 문서를 파일에서 읽으며 실제 코드를 구현해라.

목표는 내 PC(i7-13700F, RAM 32GB, RTX 3060 Ti 8GB)에서 사용하는
한국어 AI 강사 작동 버전이다.
로컬 LLM 실행과 실제 QLoRA 학습, 채팅·관리자 UI, 학습·모델 구조 확인,
교육자료 검색, 사진 원문 확인, 칠판·음성·교체 가능한 2D 아바타,
중간 질문 대응, 테스트와 실행 문서까지 연결해라.

계획만 쓰고 끝내지 마라. 매 단계 테스트가 통과하면 다음 단계도 할지 묻지 말고 이어가라.
명세 범위의 구현 → 실행 → 테스트 → 오류 수정 → 기록을 계속해라.
여러 작업이 가능하면 GPU가 없어도 가능한 독립적인 기능부터 진행해라.
실제 막힌 외부 조건은 명시하되, 그 이유로 가능한 나머지 구현까지 포기하지 마라.

단, 허위 성공 보고·사용자 파일 훼손·무단 업로드·무제한 학습·권한 우회는 하지 마라.
사용자 PC에서 실행하지 않은 테스트를 실행했다고 하지 마라.
세션 제한에 도달하면 STATUS.json과 HANDOFF.md에 완료 증거와 다음 명령을 남겨라.
최종 보고는 실제 완료/미검증/차단/추후 확장으로 나누고, 미완료를 완료로 포장하지 마라.

이것은 통합 실행 지시다. 첫 단계만 하고 사용자의 추가 지시를 기다리는 방식이 아니다.
지금 작업 공간 확인부터 시작해라.
