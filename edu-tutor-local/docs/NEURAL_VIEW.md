# 신경망 보기 · 관리자 사용 안내

주소: **http://127.0.0.1:8000/#neural**. 기존 왼쪽 관리자 메뉴의 **신경망 보기**로도 들어갑니다. 로컬 연결에서 `.local/auth-token` 파일을 불러옵니다. 모델 다운로드·새 학습 없이 설치된 텍스트 Qwen3와 선택한 기존 어댑터를 사용합니다.

## 관찰하기

1. **질문으로 계산 관찰**에 질문을 쓰고 **기본 경량 · 호출·토큰**을 선택합니다. 새 토큰은 이 화면에서 최대 128개입니다. 기존 채팅·교육 평가의 256/512토큰 조건은 바꾸지 않았습니다.
2. 실행 버튼으로 질문을 보냅니다. 다른 GPU 작업이 있으면 기다리거나 그 작업을 먼저 종료합니다. 로딩 중과 실제 호출 수신 중을 구분하며, 종료하면 모델 프로세스가 내려갑니다.
3. 구조도에서 층을 선택해 실제 모듈 경로·입출력 shape·dtype·장치를 확인합니다. **확인된 블록 내부 경로**는 설치된 forward 코드로 확인한 설명이고, 세부 연산별 실측이 아닙니다. 확대·축소·화면 맞춤, 스크롤/드래그/방향키 이동을 지원합니다.
4. 작은 값을 보려면 실행 전에 실제 블록을 최대 2개 선택하고 **선택 층 상세 · 작은 값 표본**을 선택합니다. 기본 16 생성 step 간격으로 마지막 유효 토큰의 앞쪽 최대 32개 성분을 전송합니다. 미선택·미측정 값은 만들지 않습니다.

토큰은 모델이 글을 처리하는 작은 단위이며 문자 수가 아닙니다. 층은 숫자를 바꾸는 계산 단계, 활성값은 그 입력으로 계산한 중간 숫자, 가중치는 학습으로 조정되는 내부 숫자입니다. 추론은 현재 가중치로 생성하는 작업이고 학습은 손실에 따라 학습 가능한 가중치를 갱신하는 작업입니다. 이 화면은 생각·의도·정답 이유를 읽거나 교육 정확성을 증명하지 않습니다.

## 표시와 측정 범위

| 표시 | 의미 |
|---|---|
| LIVE | 실제 실행 중인 같은 요청에서 최근 worker 이벤트를 새로 수신 |
| STATIC | 마지막에 확인한 구조. 현재 텍스트 모델 실행을 뜻하지 않음 |
| STALE | 실행 중이어도 계측 꺼짐·수신 중단·대기·화면 일시정지 |
| UNAVAILABLE | 확인한 구조 또는 지원되는 관측 정보 없음 |
| REPLAY | 선택해 저장한 실제 과거 기록. 원래 run/시각과 재생 속도 표시 |

실선은 Qwen3 forward로 확인한 블록 수준 경로이고, 입력·토큰 선택·생성 결과의 점선은 설명용 연결입니다. 개별 뉴런·전체 가중치 그림이나 완전한 계산 그래프가 아닙니다. 층 수는 config와 로딩 객체의 실제 블록 목록을 대조합니다. PEFT 래퍼·기반 모델·LoRA 경로를 구분하며, 공유 파라미터 **객체**를 중복 집계하지 않습니다. 양자화 저장 요소 수와 원본 논리적 파라미터 수는 다를 수 있고 노드별 수를 더하면 공유 항목이 겹칠 수 있습니다. `requires_grad` 및 training mode와 현재 학습 작업은 다릅니다.

경량 모드는 상위 블록·임베딩·마지막 정규화·출력 head의 호출 순서, shape, dtype, 장치, 호출 횟수와 실제 tokenizer ID를 읽습니다. 블록 메타데이터는 기본 **4 생성 step마다** 기록하며 모든 실제 호출 횟수는 계속 셉니다. 의도적으로 생략한 메타데이터 수(`aggregated_events`)와 큐 유실은 다릅니다. forward·토큰은 매 step 기록합니다. 실제 cache 길이와 생성 호출 맥락으로 prefill/decode를 구분합니다. 첫 입력이 한 토큰이어도 prefill이며, KV cache 재사용 시 과거 전체 문장을 매번 새로 계산한다고 표현하지 않습니다. 한글 본문은 기존 streamer의 출력으로 갱신하고 누적 tokenizer 디코딩은 토큰 metadata로 구분합니다. 불완전한 토큰의 대체 문자가 본문을 덮어쓰지 않습니다. 문자열 길이를 토큰 수로 쓰지 않습니다.

Python 훅 시각과 구간은 **호스트에서 관측한 호출**입니다. GPU 완료/커널 시간은 **null·미측정**이며 상시 profiler, 매 층 `cuda.synchronize`, 전체 attention/logits/hidden state 수집은 사용하지 않습니다. 상세 표본만 작은 detach 결과를 CPU로 옮깁니다. 이 전송·통계 비용도 기록합니다. 모든 히트맵은 −4~+4 공통 색 범위이며 범위 밖은 색만 포화됩니다. 표본 평균은 전체 층 평균·단어의 의미·확신이 아닙니다.

화면은 기본 250ms 단위로 모아 표시하며 설정에서 바꿀 수 있습니다. 관측 시각·UI 수신·표시 시각을 따로 보여 줍니다. GPU를 sleep시키거나 모든 층을 천천히 밝히지 않습니다. 최근 관측한 여러 블록을 강조하며 화면이 GPU의 매 순간을 그대로 보여 주지는 않습니다.

## 중단·재연결·저장

**화면 일시정지**는 표시만 멈춥니다. **관측 끄기**는 훅을 다음 생성 경계에서 제거하며 답변 생성은 계속됩니다. **모델 작업 취소**는 기존 작업 취소 경로를 사용합니다. OFF로 시작한 성능 기준 실행은 원래 무훅 경로를 유지하므로 중간에 관측을 켜려면 다음 실행을 경량으로 시작합니다.

탭을 닫으면 SSE 연결이 해제되고 마지막 관찰자가 없어질 때 훅이 꺼집니다. 여러 창은 한 worker의 관측을 공유하며 훅을 중복 설치하지 않습니다. 명시적인 관측 끄기는 그 실행 전체에 적용합니다. 재연결은 실행 상태·요청 ID·epoch·순번을 확인합니다. 서버 재시작 전 이벤트는 새 실행에 합치지 않습니다.

기본 저장은 메모리입니다. worker IPC·backend·UI 버퍼는 유한하며 일반 층 호출 기록은 밀려날 수 있습니다. 유실·집계 수와 순번 간격을 표시합니다. 입력/출력 토큰 및 종료 상태는 별도 보존합니다. 느린 브라우저가 생성 루프를 기다리게 하지 않습니다. 화면은 최근 600개, 타임라인은 주요 최근 100개이며 backend 전체 기록과 다릅니다.

**현재 기록 저장**은 현재 메모리에 남은 이벤트를 저장합니다. 기본은 원문·토큰·활성값 제외이며 이를 영구 보관하려면 별도 체크해야 합니다. 회차 누적 20MB·전체 200MB 제한에 걸리면 저장을 중단하고 기존 파일은 삭제하지 않습니다. 저장 위치는 현재 D 드라이브의 `.local/neural-records`이며 프로젝트 총 저장공간 정책에도 포함합니다. 구조 metadata cache는 `.local/models/text/neural-structure.json`입니다. 인증 정보는 URL에 넣지 않고 Bearer 헤더로 SSE에도 적용합니다.

저장 기록 선택 후 **기록 재생**을 누르면 원래 이벤트 시각 간격으로 1x/0.25x 재생합니다. 원문 제외 기록에는 토큰·활성값을 채워 넣지 않습니다. 재생은 새 GPU 실행이 아닙니다.

## 학습 지표와 오류 복귀

학습 지표 탭은 기존 training worker의 `Bounds.on_log`가 저장한 `metrics.jsonl` 및 manifest를 읽습니다. 과거 50 optimizer step과 316 microbatch 기록은 **과거 학습 기록**입니다. 현재 승인된 학습이 없으면 **현재 학습 작업 없음**을 표시합니다. 이후 실제 학습이 승인되면 같은 callback 기록을 갱신해서 읽도록 연결했으며 이번 변경으로 학습을 실행하지 않았습니다.

설치된 단일 GPU Trainer 경로의 `grad_norm`은 필요시 AMP unscale 후 `clip_grad_norm_`가 반환한 clipping 전 전체 norm입니다. clipping 후 norm·층별 gradient·가중치 변화·과거 활성값은 별도 미측정입니다. optimizer step은 실제 갱신 횟수이고 microbatch/gradient checkpoint 재계산 횟수와 구분합니다. 실시간 GPU 학습 시각화 검증은 이번 범위에서 **NOT RUN**입니다.

관측 오류는 계측을 중지하고 원래 생성 작업은 계속하도록 처리합니다. 화면 오류 시 **관측 끄기** 후 기존 **채팅/강의실** 메뉴로 돌아갑니다. 모델 실행 자체 오류·GPU 메모리 부족 등은 원래 작업 오류로 남으며 완성 답변으로 표시하지 않습니다. 다른 비전·음성 작업이 GPU를 쓰면 텍스트 모델이 현재 상주한다고 표시하지 않습니다.

## 실행 증거

실제 GPU 8회 이내 검증은 `runs/neural/current/gpu/attempts.json`, 질문·run ID·실제 SSE 기록은 같은 폴더의 각 JSON, 출력 일치·속도·VRAM 비교는 `runs/neural/current/gpu-summary.json`에 있습니다. 자동 검증은 별도 제한 ledger를 사용하고 기존 모델 예산도 차감합니다. 이 기록의 질문은 수락 검사용 합성 질문이며 요청된 증거 보관을 명시해 저장합니다. 실제 브라우저 증거는 `runs/neural/current/browser/`입니다. CPU 단위 검사·fixture UI·실제 GPU·과거 학습 표시를 합쳐 한 종류의 증거라고 보고하지 않습니다.

세부 검증 결과와 남은 한계는 [신경망 관측 인수 기록](NEURAL_ACCEPTANCE.md), 전체 상태는 [STATUS.json](../STATUS.json)을 확인합니다. 기존 교육 정확성 NOT_READY 및 사람 검토 미실시 상태는 유지합니다.

기술 근거는 설치된 torch 2.9.1+cu128, transformers 4.57.3, peft 0.18.1의 실제 소스와 [PyTorch hooks](https://docs.pytorch.org/docs/2.9/generated/torch.nn.Module.html), [CUDA 비동기 실행](https://docs.pytorch.org/docs/2.9/notes/cuda.html), [CUDA Event](https://docs.pytorch.org/docs/2.9/generated/torch.cuda.Event.html), [Transformers streamer](https://huggingface.co/docs/transformers/v4.57.3/en/internal/generation_utils)입니다. 설치 패키지·precision·드라이버를 변경하지 않았습니다.
