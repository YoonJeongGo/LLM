# 자료와 데이터

교육자료 검색 corpus, 추가 학습 dataset, 독립 평가 dataset은 별도 경로다. 업로드 자료는 출처·권리 메모와 검토 상태를 저장한다. 검색 인덱싱은 모델 가중치 학습이 아니다. 사용자 대화·사진·오답은 자동으로 학습 데이터에 들어가지 않는다.

`data/demo`에는 직접 생성한 학습 25개, validation 8개, test 12개가 있다. 모두 `generated_unreviewed`, `demo_only=true`. 실행 가능한 SQLite 정답은 machine 검증할 수 있으나 설명 전체의 인간 검토를 의미하지 않는다. 원본 기출/유료 교재의 복제 데이터가 아니다.

검사는 스키마·역할 순서·권리·완전 중복·family 분할과 SQL 구조 정규화로 단순 이름/숫자 변경 누수를 잡는다. 이것이 모든 의미적 중복을 제거했다고 보장하지 않는다. CLI validator의 production profile은 미검토 메타데이터를 거부하지만 검토자의 신원을 인증하는 승인 시스템은 아니다. 현재 웹/CLI GPU 학습은 demo만 허용하며 운영용 학습은 지원하지 않는다. 실제 Qwen tokenizer로 response-only target 경계/EOS/padding/길이를 별도로 확인한다.

학습 화면의 토큰 검사는 설치된 실제 토크나이저로 수행하며 대상 데이터 해시와 유효/제외 이유를 표시한다. 평가 화면의 사람 점수는 직접 입력해야 저장되고 기본 점수나 AI 대리 평가를 채워 넣지 않는다. 검토 기록은 대상 보고서 SHA256와 함께 추가 저장하며 기존 결과를 덮어쓰지 않는다.
