# v0.2 실행 제한과 측정 해석

현재 PC의 `.local/phase2-policy.json`이 이번 회차 제한을 활성화한다. 신규 모델 다운로드와 기존 기반모델의 추가 GPU 학습은 중단한 상태다. 전체 회귀 검사에는 격리된 무작위 소형 CPU LoRA 배선 검사가 포함되며, 기존 기반모델·어댑터 학습과 구분한다.

`models/budget.py`는 모델 프로세스 실행 전에 최대 300초를 영속 예약하고, 종료 후 실제 벽시계 시간으로 정산한다. 중단된 서버가 정산하지 못한 예약은 보수적으로 전액 사용 상태로 남는다. 모델 로딩·프로세스 시작·실패도 누적90분에 포함한다. 이는 GPU 커널의 순수 실행 시간이 아니다. 새 음성 시도12개와 사진 추론4회는 실패해도 차감하며, 유효한 캐시 사용은 새 음성으로 세지 않는다.

저장공간은 decimal GB다. 시작 전체 조사에서 환경·모델·임시파일·미디어와 공유 pip 캐시 및 공유 Python 런타임 전체를 보수적으로 포함했다. 공유 부분 중 정확히 이 프로젝트에만 귀속되는 양은 알 수 없다. 실행 중에는 고정 부분의 시작 상한과20MB 코드 변경 여유에 `runs`와 전체 `.local`의 현재 크기를 더해50GB 제한을 확인한다. 종료 시 전체를 다시 조사한다. C여유50GB 조건도 요청 전 확인하며 자동 삭제·이동은 하지 않는다.

텍스트 모델은 요청별 프로세스에서 로딩하고 종료한다. 후속 요청의 OS 파일 캐시 효과를 GPU 모델 상주 상태로 부르지 않는다. TTS는 최대4개의 짧은 단위를 같은 모델에서 순서대로 생성한다. 완성된 첫 클립부터 API에 게시하며, UI는 다음 클립 작업이 계속되는 동안 첫 단위를 재생할 수 있다. 모델 상주 서비스를 일반 구현한 것은 아니다.

처음 실제 보충 음성은27.6초·64.72초로 길었고, 후자는 작업에262.3초가 걸렸다. 기존 결과는 보존했다. 수정은 공유 계산값으로 보충 대사를 짧게 구성하고, 새 TTS 요청을768코드 토큰·35초 음성 이내로 제한한다. 종료 토큰이 관측되지 않거나 음성이 길면 정상 클립으로 제공하지 않는다. 종료 검사의 첫 구현은 숨은 상태를 참조해 관측에 실패했고, 최종 구현은 실제 생성 토큰열을 검사한다. 이 실패도 작업·예산 기록에 남는다.

설치된 Transformers4.57.3의 `GenerateDecoderOnlyOutput.sequences`는 생성 토큰열이고, hidden_states는 생성 단계별 상태이므로 마지막 종료 토큰의 다음 상태가 없을 수 있다. 검사에는 전자를 사용한다. [공식 생성 출력 문서](https://huggingface.co/docs/transformers/v4.57.3/en/internal/generation_utils#transformers.generation.GenerateDecoderOnlyOutput).

종료 토큰·유한 비무음 파형·길이 확인은 실제 발화 내용, 발음, 자연스러움, 학습 이해도를 증명하지 않는다. 대사와 판서의 계산값 일치는 프로그램으로 검사하지만, 청취 품질은 사람 검토 대기다. 초기 실제 전체 지연과 이후 캐시 재생 또는 저장 답변으로 대사만 바꾼 재생 지연을 합쳐서 보고하지 않는다.

사진 소비자가 transcription 이벤트에서 바로 반환해 뒤의 done을 읽지 않던 결함도 수정했다. 최초 세 실제 전사는 API 성공이었으나 예산 원장의 상태가 failed_or_cancelled로 기록됐다. 사용 시간·사진 횟수 차감은 유지되며 과거 원장을 덮어쓰지 않았다. 최종 소비자는 완료 이벤트와 프로세스 종료 검증을 모두 소비한 뒤 결과를 게시한다. 마지막 허용 네 번째 사진 추론은 이 경로에서 succeeded/completed를 확인했다. 세 최초 기록은 OCR 성공/실패를 판단할 때 원문·API 작업 상태와 함께 읽는다.
