# 검증 한계

로컬 기능 검증은 완료했지만 교육 실사용 정확도는 미달이다. 자세한 증거는 STATUS.json/ACCEPTANCE.md에 기록했다.

독립 SQL 평가에서 기반 모델 3/11, 50단계 어댑터 3/11이었다. 12개 응답 중 잘림은 0개에서 2개로 증가했다. RAG를 붙인 실제 COUNT 문제도 존재하지 않는 열을 참조했고, 생성된 강의는 이 오류를 반복했다. 구조화 강의·음성 생성 성공은 정답 또는 좋은 교육이라는 뜻이 아니다. 어댑터를 자동 적용하지 않았다.

실제 한국어 WAV 3개(7.84초, 9.12초, 13.84초)는 생성·체크섬·파형·브라우저 재생을 검증했다. 사람의 발음·자연스러움 평가는 미실시다. 사진 3개를 실제 읽었지만 글자 오인식이 있고 표는 원문 문자열에만 나타나 구조화 tables가 비어 있었다. 잘린 조건은 별도 보수적 형식 검사로 풀이를 막지만 모든 종류의 누락을 탐지하지는 못한다.

데모는 데이터베이스 기초에 한정한다. 45문제나 제한된 학습으로 모든 과목의 정확도·일반화 성능을 보장하지 않는다. 사람이 검토하지 않은 설명과 음성은 H=not_reviewed다. CPU fixture UI 테스트는 실제 모델 연결 장치 테스트가 아니다.

SQLite만 실행 검증한다. Oracle 전용 문법은 실행되지 않았다고 표시한다. 사진의 수식/표/잘린 조건은 사용자 확인이 필요하다. 2D 기본 아바타는 자체 SVG이며 실사 강사·한글 획순·phoneme lip-sync를 생성하지 않는다.

CUDA 검증은 이 Windows/RTX3060Ti BF16 환경에 한정한다. FP16 fallback, WSL/Linux, 다른 GPU는 별도 미검증이다. hardware OOM은 고의 유발하지 않았다. 여러 사용자가 공유하는 공개 서비스로 배포하지 않는다.

중간 질문 후 실제 원강의 ID/단계/진행률 복원은 검증했으나, 실제 중단 시점의 판서는 clear 이후라 비어 있었다. 내용이 있는 표 복원은 fixture 테스트 근거다. 기본 아바타는 한 관절 회전·포인터와 RMS 입 움직임이며 완전한 인체 리깅이나 음소별 입 모양이 아니다.

운영용 학습·검토자 신원 인증·optimizer/RNG 상태의 중단 재개는 미지원이다. 취소 시험에서 남은 어댑터는 가중치 사본이며 재개 체크포인트가 아니다. 새 환경에서 전체 설치를 재현한 것은 아니며 소스 ZIP은 모델·환경·개인 데이터 백업을 대신하지 않는다.
