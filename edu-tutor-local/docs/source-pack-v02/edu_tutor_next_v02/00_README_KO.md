# AI 강의실 — v0.1 이후 후속 개선 지시서

이것은 완성 앱이나 수정된 앱 소스가 아니라 **기존 앱을 개선하기 위한 Codex 지시서**다.
ChatGPT는 사용자가 붙여 넣은 README·검증 보고서와 원래 명세를 읽었지만,
사용자 PC의 D:\LLM\edu-tutor-local 코드·실행 화면·runs를 직접 감사하지 않았다.
동봉 SQL 예제의 기준 결과만 이 파일을 만든 환경의 SQLite에서 확인했다.

## 목표
학생이 텍스트/사진으로 모르는 부분을 묻고, 캐릭터가 정확한 내용과 실제 판서를
연결해 설명하며, 중간 질문에 기존 칠판을 유지해서 대응하는 개인 튜터다.
미리 만든 강의 재생, 답변 낭독 아바타, 장시간 학습 자체가 목적이 아니다.

## 전달 방법
이 폴더를 기존 프로젝트 안에 넣고 01_START_PROMPT_KO.txt를 Codex에 보낸다.
02_NEXT_SPRINT_SPEC_KO.md와 03_ACCEPTANCE_KO.md가 이번 변경 범위다.
기존 앱을 초기화하지 않으며 설치·학습을 처음부터 반복하지 않는다.

## 이번에 하지 않는 것
새 모델 자동 다운로드, 추가 GPU 학습, 교사 모델과 무한 대화,
유료 호출, 외부 업로드, 저장 위치 강제 이전, 프레임워크 전면 교체.
기존 모델의 한계가 확인되면 근거와 비교 계획을 남기며 성공을 꾸미지 않는다.

## 파일
- 01_START_PROMPT_KO.txt: 바로 전달할 시작 지시
- 02_NEXT_SPRINT_SPEC_KO.md: 오답 진단·검증·실시간 수업 개선
- 03_ACCEPTANCE_KO.md: 실제 입력/화면/음성으로 확인할 검증 기준
- BASELINE_REPORTED.json: 사용자가 전달한 이전 결과; 독립 검증 결과가 아님
- fixtures/sql_cases_v02.json: 개발용 SQL 회귀 예제 18개; 비공개 성능 시험이 아님
- tools/verify_fixture_oracles.py: 위 예제의 SQL 기준값만 확인하는 검사기
- SOURCE_NOTES_KO.md: 문서 근거와 적용 범위
- PACK_VALIDATION.json: 지시서 예제 검사 결과; 사용자 앱 테스트 결과가 아님

이 지시서의 합격 기준은 프로젝트 내부 품질 게이트다. 교육 제품 인증이나
전 SQLD 범위의 정확도 보장이 아니며, 인간 청취·교육 검토는 별도로 필요하다.
